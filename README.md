# 關鍵字遊戲
## 使用教學

### 關鍵字清單
---
#### 隨機關鍵字
點擊會隨機顯示該清單中的關鍵字
#### 複製使用者連結
可以複製該清單的使用者連結給別人

### 關鍵字生成器
---
建立屬於你的關鍵字清單
#### 建立清單
打好該清單名稱，點擊即可建立清單
#### 尋找清單
尋找你想變更的清單
#### 刪除清單
刪除不要的清單
#### 建立關鍵字
在目前的清單中建立關鍵字
#### 刪除關鍵字
在目前的清單中刪除關鍵字

### 側邊攔
---
#### 開啟/關閉目錄
開啟或關閉側邊攔
#### 儲存變更
儲存目前變更(限本地)
#### 選擇清單
選擇你想要隨機生成關鍵字的清單
#### 關鍵字生成器按鈕
點擊可進入關鍵字生成頁面
#### 設定按鈕
點擊可進入設定頁面

### 設定
---
#### 複製開發者連結
點擊可複製完整開發者頁面連結
#### 還原原始頁面
點擊可清除所有您儲存的變更
